# Uso de marcas

## Identidad de RutaMérito

Este documento establece criterios generales para el uso de los siguientes elementos:

- RutaMérito™
- Ruta al Mérito™
- ¡¡¡Tu camino al éxito!!!
- Logotipos
- Identidad visual

## Regla general

La disponibilidad pública de un repositorio, código o documentación de RutaMérito™ no significa que cualquier persona pueda utilizar libremente la marca, el nombre, el lema o la identidad visual.

El uso de estos elementos requiere autorización cuando corresponda y debe respetar los derechos aplicables.

## Usos no permitidos

No se debe utilizar la identidad de RutaMérito™ de una forma que:

- Genere confusión sobre el origen de un producto, servicio, contenido o proyecto.
- Sugiera autorización, afiliación, patrocinio, representación o asociación inexistente.
- Presente un proyecto independiente como si fuera oficial.
- Modifique, combine o reproduzca logotipos e identidad visual de manera engañosa.
- Utilice el nombre o el lema para promocionar productos o servicios sin autorización.

## Referencias informativas

Una referencia descriptiva y veraz a RutaMérito™ puede utilizarse cuando resulte necesaria para identificar el origen, contexto o naturaleza de un recurso, publicación, material educativo o contenido relacionado con sus proyectos.

Las referencias deberán limitarse a información objetiva y comprobable, respetando en todo momento la identidad y denominaciones oficiales de la marca. La mención de RutaMérito™ no deberá presentarse de manera que pueda interpretarse como patrocinio, asociación, autorización, certificación, representación, alianza comercial o respaldo de una persona, empresa, institución, producto o servicio cuando dicha relación no exista.

Cuando sea necesario identificar un recurso desarrollado por RutaMérito™, podrán utilizarse referencias claras como:

- "Recurso desarrollado por RutaMérito™"
- "Material elaborado por RutaMérito™"
- "Fuente: RutaMérito™"

La fórmula utilizada deberá corresponder realmente a la naturaleza del recurso o contenido.

Las referencias deberán conservar el nombre de la marca sin alteraciones, evitar modificaciones que puedan generar confusión y, cuando sea apropiado, dirigir al sitio web oficial:

https://rutamerito.github.io/

La utilización de logotipos, elementos gráficos, capturas de pantalla u otros recursos de identidad visual se encuentra sujeta a las condiciones establecidas en esta política y no se entiende autorizada por el simple hecho de realizar una referencia textual.

Ante usos que excedan una referencia meramente informativa, especialmente cuando involucren el logotipo, materiales protegidos, publicidad, promoción, actividades comerciales o una posible asociación con RutaMérito™, deberá solicitarse autorización previa a través de los canales oficiales de contacto.

Las solicitudes de autorización serán evaluadas de manera individual, de acuerdo con la naturaleza, finalidad, alcance y contexto del uso solicitado. La autorización deberá obtenerse antes de realizar el uso correspondiente y no se presume por el silencio o la ausencia de respuesta.
